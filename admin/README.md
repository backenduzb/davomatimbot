Clone repository and enter folder

```bash
git clone https://github.com/backenduzb/EDavomat && cd EDavomat 
```

<h2>For locally run</h2>

Install librarys with poetry

```bash
poetry install
```


Install librarys with venv

```bash
python -m venv .venv
source ./.venv/bin/activate
pip install -r requirements.txt
```

<h2>Build & Run with docker</h2>

```bash
docker-compose up --build
```
